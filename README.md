# Bangladesh Boxing Federation — Official Website

GitHub Pages-ready static website for Bangladesh Boxing Federation.

## কীভাবে ব্যবহার করবেন
1. এই `bbf-website` ফোল্ডারের সব ফাইল GitHub repository-তে upload করুন।
2. `assets/images/`-এ আপনার আসল tournament, staff ও gallery photos দিন।
3. আসল federation logo `assets/images/placeholder.svg`-এর জায়গায় ব্যবহার করতে চাইলে HTML-এর logo path বদলান বা একটি PNG/JPG path দিন।
4. `data/site-data.js`-এ title, year, venue, description ও staff information update করুন।
5. GitHub → Settings → Pages → Deploy from branch নির্বাচন করুন।

## বর্তমান কাঠামো
- Home / Federation Overview
- Selected International Events
- Selected National Competitions
- Officials & Staff
- Photo Gallery
- 2026–2031 Selected Five-Year Plan Highlights
- Contact / Office Information
